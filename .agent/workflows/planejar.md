# /planejar

Antes de escrever qualquer código, produza um plano de implementação.

1. Reescreva o objetivo em uma frase.
2. Liste as premissas que está assumindo. Sinalize as que tiver dúvida.
3. Se houver múltiplas abordagens, nomeie-as e escolha uma — explique o porquê.
4. Divida o trabalho em etapas com uma verificação para cada uma:

```
1. [Etapa] → verificar: [critério]
2. [Etapa] → verificar: [critério]
3. [Etapa] → verificar: [critério]
```

5. Faça perguntas de esclarecimento antes de prosseguir.

Não escreva código até que o plano seja confirmado (explícita ou implicitamente pelo usuário).
